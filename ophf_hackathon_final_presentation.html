What we achieved

Hardened the SPIFFE/SPIRE security pattern in the Commercial SDV Stack

Starting from Blueprint PR #5, we tightened workload identity, shrank the attack surface, made authorization fail closed — and proved all of it with tests and CI.

Fail closed

Default-deny authorization

PMC Rego policy now uses default allow := false; anything other than an explicit true is denied. No more Undefined-result loopholes.

Identity

Content-addressed attestation

Workloads attested by image config digest, not a mutable :latest tag. Only the exact approved image gets an SVID — any change revokes identity.

Attack surface

CDA off the network

TCP 20002 removed. SOVD served only on a protected Unix socket (mode 0770, group sovd-clients) — the kernel decides who can even connect.

Attack surface

Workload API hardened

Agent socket mounted read-only + nocopy; workloads run non-root with cap_drop: ALL. No workload can impersonate SPIRE anymore.

Proof

End-to-end authz tests

Cargo test matrix of authorized and unauthorized callers checks 401 vs. 403 over the real Unix socket — plus offline tests for SPIRE outages.

Proof

CI on every change

Prebuilt, content-hashed images on GHCR keep full authorization runs at ~5 minutes; a new workflow runs all uService unit tests.

Every item reviewed and merged as its own PR into the hackathon branch — now bundled as one upstream PR on top of #5.
